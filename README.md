# SKLAD · Зал

Учёт склада зала: стеллаж как в зале, инвентаризация, автодозаказ по периодам спроса и отчёты.

## Открыть в браузере (без скачивания)

**Демо:** https://thieveoflettuce.github.io/sklad-zal/

На странице репозитория справа в блоке **About** тоже будет ссылка **Website** — по ней приложение открывается сразу.

## Локально

```bash
npm install
npm run dev
```

http://localhost:3000

## Первый запуск Pages (один раз)

1. GitHub → репозиторий **sklad-zal**
2. **Settings → Pages**
3. **Build and deployment → Source:** GitHub Actions
4. Запушь изменения — workflow сам соберёт и опубликует сайт

Кухня, бар, техкарты и админка — следующие этапы.
